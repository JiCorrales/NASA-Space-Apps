# Use of AI tools

The NASA Space Apps Challenge allows AI tools and requires teams to state where and how they were used.

## Code and documentation

Parts of the code and documentation in this repository were written with the assistance of Claude Code
(Anthropic). Commits made with its assistance carry the trailer `Assisted-by: Claude Code`.

## Images, video, audio and 3D models

AI-generated images and video carry a visible watermark. List each generated asset here.

| Asset | Tool | Location in the repo |
|---|---|---|
| Starfield mesh: 1500 star quads at random directions, drawn by `ShipBuilder.Starfield()` from a fixed seed (procedural code written with Claude Code; no image model) | Claude Code (code), Unity editor (generation) | `Assets/_Project/Art/Meshes/Starfield.asset` |
| Round-room wall mesh: the inner face of the wall as one mesh with metre-based UVs, built by `ShipBuilder.WallMesh()` (procedural code written with Claude Code; the hull texture on it is the Poly Haven one in `CREDITS.md`) | Claude Code (code), Unity editor (generation) | `Assets/_Project/Art/Meshes/RoomWall.asset` |
| Deck plate texture: steel plates with seams, bolts and tread, drawn pixel by pixel by `ShipBuilder.DeckTexture()` from a fixed seed (procedural code written with Claude Code; no image model) | Claude Code (code), Unity editor (generation) | `Assets/_Project/Art/Textures/DeckPlates.png` |
| 3D models: CubeSat bodies (1U, 3U, 6U), solar wing, UHF and S-band antennas, six instrument models, ship console, corridor segments, ceiling light strip and Earth sphere. | Pixel-art planets and CubeSat of the 2D screens: SVG rectangles drawn by React components at run time (code written with Claude Code; no image model, no image files) | Claude Code (code) | `web/src/screens/parts/PixelPlanet.tsx`, `web/src/screens/parts/PixelCubeSat.tsx` |
